# AI Selector

Extensión de Chrome: selecciona texto en cualquier página y resuélvelo con IA al instante usando la API de Groq.

## Instalación

1. Abre `chrome://extensions`.
2. Activa el **Modo desarrollador**.
3. Pulsa **Cargar descomprimida** y elige esta carpeta.

## Uso

1. Haz clic en el icono de la extensión y configura tu API Key de Groq (gratis en [console.groq.com/keys](https://console.groq.com/keys)).
2. Selecciona texto en cualquier página.
3. Haz clic en el botón flotante para obtener la respuesta.

La API key se guarda solo en Chrome y únicamente se envía a Groq para hacer la consulta.
